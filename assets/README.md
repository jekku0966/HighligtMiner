# HighlightMiner branding

Approved icon and matching splash artwork, reused from the September 7 branding session.
The splash reads "HighlightMiner" and "Find the good bits.".

`highlightminer.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel Windows icons converted from `highlightminer-icon.png`.
The executable embeds the icon. Artwork source files are not copied to the portable release root.

The splash is retained as a source asset but deliberately not enabled for beta1.
Its focus and shutdown behavior alongside the pywebview desktop window has not been verified on Windows.
