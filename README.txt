HighlightMiner v0.2 Beta

HighlightMiner analyzes long videos and VODs and suggests moments that may be worth clipping.

QUICK START

1. Extract the whole ZIP file.
2. Run HighlightMiner.exe.
3. Choose a video or VOD.
4. Choose your analysis settings.
5. Start analysis.
6. Review the suggested highlights.
7. Adjust clip start and end points as needed.
8. Export the clips you want to keep.

FIRST START

Your first analysis may take longer if the selected speech recognition model
needs to be downloaded. HighlightMiner asks before downloading it.

NVIDIA GPU

The official Windows package includes portable CUDA runtime files for supported
NVIDIA GPUs. CPU processing is also available.

IMPORTANT

Keep HighlightMiner.exe in this folder. The bin, runtime, _internal and
.streamlit folders are part of the application. Your settings and review
history are stored alongside the app, so extract it to a folder you can write to.

WINDOWS SMARTSCREEN

This beta is not code-signed and may show a Windows SmartScreen warning.
Download it only from the official release source. You can check the supplied
SHA256SUMS.txt to verify the download.
